# Isothrum desktop

The Isothrum editor in a window, plus what a browser can't do: **run a lab on this machine**,
**open a console** on its machines, **start, stop and snapshot** them, and **capture traffic**.

- **The editor is bundled** (`editor/`, built from the website by `npm run editor`): the app
  works offline. Accounts and saved projects live on isothrum.com: set
  `ISOTHRUM_URL=https://www.isothrum.com/en` to use the site in the window instead.
- **Run / Stop**: the lab's `isoloom.yml` and its Docker Compose files (generated by Isoloom's
  library, no CLI needed) are written to the app's data folder, then `docker compose up`.
  Labs made of containers (Cisco appliances included) for now; a lab with VMs is exported and
  run with `isoloom run`.
- **Console**: a terminal on a machine: a shell in its container, or SSH to a Cisco
  appliance's management address (`admin`/`admin`). The terminal is `$TERMINAL`, else GNOME
  Terminal, Konsole, Xfce Terminal, Alacritty, `x-terminal-emulator` or xterm (Terminal.app on
  macOS, cmd on Windows).
- **Start, stop, restart** one machine, with its network sidecar (its routes come back).
- **Snapshots**: a machine saved as an image (`docker commit`: its files, a router's saved
  configuration; not named volumes), restored by running the machine from it.
- **Capture traffic** on a LAN or a cable: a throwaway container (`nicolaka/netshoot`) joins
  the network namespace of a machine on that segment, finds the interface by its address, and
  streams `tcpdump` live into Wireshark, or into a `.pcap` file when Wireshark isn't installed.
- **Updates**: the app checks GitHub's latest release (signed with the app's update key) and
  offers to restart on a newer one.

The editor shows these controls only when it finds the app's bridge (`window.__TAURI__`). Only
the bundled editor, isothrum.com and `http://localhost` (developing) may call the app's
commands: see `src-tauri/capabilities/editor.json`.

## Needs

Docker, usable by your account (Linux: `sudo usermod -aG docker $USER`, then log in again).
Wireshark, to watch captures live.

## Develop

```
npm install
npm run editor                                       # the bundled editor, from ../../../isothrum-website
                                                     # (or ISOTHRUM_WEBSITE=/path/to/isothrum-website)
npm run dev                                          # the app on the bundled editor
ISOTHRUM_URL=http://localhost:3000/en npm run dev    # against a local build of the website
cd src-tauri && cargo test                           # the runner
cd src-tauri && sg docker -c "cargo test -- --ignored"   # its tests that need Docker
npm run build                                        # .deb / AppImage / .dmg / .msi
```

## Release

Push a tag (`git tag v0.2.0 && git push --tags`): `.github/workflows/release.yml` builds the
installers for Linux, macOS (universal) and Windows on a **draft** release, with `latest.json`
for the updater. Publish the draft when it looks right.

Secrets of the repository (Settings → Secrets → Actions):

| Secret | What |
| --- | --- |
| `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | The update key (set). Its public half is in `tauri.conf.json`; keep the private one backed up (it was generated into `~/.isothrum/updater.key`). |
| `WEBSITE_REPO_TOKEN` | A read-only token for `isoloom/isothrum-website` while it is private (the editor is built from it). |
| `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY` | The Developer ID Application certificate (.p12, base64), its password, its name. |
| `APPLE_ID`, `APPLE_PASSWORD`, `APPLE_TEAM_ID` | Notarization: the Apple ID, an app-specific password, the team. |
| `WINDOWS_CERTIFICATE`, `WINDOWS_CERTIFICATE_PASSWORD` | The code-signing certificate (.pfx, base64) and its password. |

Builds are unsigned (for macOS and Windows) until those secrets exist. The updater downloads
from GitHub releases: it works once the repository is public.

A local *production* build of the website served over http needs `LOCAL_HTTP=1` at build time:
WebKit doesn't exempt localhost from `upgrade-insecure-requests`.
