# Isothrum desktop

The editor from [isothrum.com](https://www.isothrum.com) in a window, plus what a browser can't
do: **run a lab on this machine** and **capture its traffic**.

- **Run / Stop**: the lab's `isoloom.yml` and its Docker Compose files (generated by Isoloom's
  library, no CLI needed) are written to the app's data folder, then `docker compose up`.
  Labs made of containers for now; a lab with VMs is exported and run with `isoloom run`.
- **Capture traffic** on a LAN or a cable: a throwaway container (`nicolaka/netshoot`) joins
  the network namespace of a machine on that segment, finds the interface by its address, and
  streams `tcpdump` live into Wireshark, or into a `.pcap` file when Wireshark isn't installed.
  Like GNS3's capture on a link.

The window loads the hosted editor; the editor shows Run, Stop and Capture only when it finds
the app's bridge (`window.__TAURI__`). Only isothrum.com (and `http://localhost` while
developing) may call the app's commands: see `src-tauri/capabilities/editor.json`.

## Needs

Docker, usable by your account (Linux: `sudo usermod -aG docker $USER`, then log in again).
Wireshark, to watch captures live.

## Develop

```
npm install
npm run dev                                          # against isothrum.com
ISOTHRUM_URL=http://localhost:3000/en npm run dev    # against a local build of the website
cd src-tauri && cargo test                           # the runner
npm run build                                        # .deb / AppImage / .dmg / .msi
```

A local *production* build of the website served over http needs `LOCAL_HTTP=1` at build time:
WebKit doesn't exempt localhost from `upgrade-insecure-requests`.
